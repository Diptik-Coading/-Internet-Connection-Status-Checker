# Internet Connection Status Checker 🌐

A simple web-based Internet Connection Status Checker built using **HTML, CSS and JavaScript**.

## Features

- 📶 Check Internet connection status
- 🌐 Display public IP address
- ⚡ Display network download speed
- 🔄 Automatically check connection when the page loads
- 🎨 Simple and clean user interface

## Technologies Used

- HTML5
- CSS3
- JavaScript

## How It Works

The application checks whether the browser is online using the browser's network status. If connected, it retrieves the public IP address and displays the available network downlink speed.

## Files

- `index.html` — Website structure
- `style.css` — Styling and layout
- `script.js` — Internet status, IP address and network information logic
